# Campus Events Guide

SW302 Assignment 1 - User Interface Development

## Project Description

Campus Events Guide is a website that helps students explore campus events, view event details, check the event schedule, and register for an event.

The website is created using HTML and CSS.

## Website Pages

- `index.html` - Home page with featured campus events.
- `events.html` - Displays upcoming and past events.
- `event-details.html` - Shows event information, media, and the review form.
- `schedule.html` - Displays the campus event timetable.
- `registration.html` - Contains the event registration form.

## Technologies Used

- HTML5
- CSS3

## Project Structure

- HTML files
- `style.css`
- `assets/` - Event images and video

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in Chrome or Microsoft Edge.

## Notes

- The website uses HTML and CSS only.
- The forms demonstrate HTML5 validation and do not store or send submissions.
